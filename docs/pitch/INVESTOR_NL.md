# Neuriy — korte investeerderstekst (NL)

**Neuriy** is een eigen AI-chatproduct, aangedreven door **ElloFive (Ello5)** — niet gehuurd van een big-tech chatmerk.

## Waarom backen?

- Inloggen via **IDHook** verplicht vóór AI
- **Marketplace** als echte pagina’s in de chat (apps/tools uploaden → AI kan ze gebruiken)
- **Ello5 leert dag & nacht** op DigitalOcean met Hugging Face-datasets + chat-feedback
- Werkende demo: chat, marketplace, settings, voice/AI-face, tests groen

## Ask

Kickstarter om always-on learning, Marketplace voor developers, en public beta te financieren.

Zie `01-pitch/STORY.md` (Engels, voor Kickstarter) en `01-pitch/INVESTOR_ONE_PAGER.md`.
