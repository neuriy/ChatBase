# Kickstarter upload checklist

## Before you start

- [ ] Create Kickstarter draft project (Technology / AI category)
- [ ] Set goal + currency (see `01-pitch/USE_OF_FUNDS.md`)
- [ ] Add team bio + profile photo

## Campaign fields

- [ ] **Title** ← `01-pitch/CAMPAIGN_TITLE.txt`
- [ ] **Subtitle** ← `01-pitch/SUBTITLE.txt`
- [ ] **Story** ← paste `01-pitch/STORY.md` (convert headings in Kickstarter editor)
- [ ] **Risks** ← `01-pitch/RISKS.md`
- [ ] **Rewards** ← `04-rewards/REWARDS.md`

## Media

- [ ] **Main video** ← `02-video/neuriy-kickstarter-demo.mp4` (+ optional voiceover from `SCRIPT.md`)
- [ ] **Gallery images** ← all PNGs in `03-screenshots/`
- [ ] Optional: crop `01-home.png` as project card image (high contrast)

## Links

- [ ] GitHub: https://github.com/neuriy/ChatBase
- [ ] Marketplace: https://github.com/neuriy/Neuriy-Marketplace
- [ ] Website / chat URL when live

## Compliance

- [ ] No unauthorized third-party brand claims (Neuriy / ElloFive only)
- [ ] Do not promise guaranteed investment returns — Kickstarter is crowdfunding for product rewards
- [ ] Review Kickstarter AI / software project rules for your region

## After publish

- [ ] Share one-pager `01-pitch/INVESTOR_ONE_PAGER.md` with angels who ask for a short brief
- [ ] Post weekly update with learning-cycle stats (`learning.entries` from Ello5 `/health`)
